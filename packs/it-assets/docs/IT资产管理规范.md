# IT 资产管理规范（示例）

本规范适用于公司配发给员工使用的笔记本、台式机、显示器、打印机和服务器。示例内容，不对应任何真实公司。

## 一、资产编号

每台设备在入库时贴资产标签，编号由类型前缀和四位序号组成：笔记本 NB、台式机 PC、显示器 MON、打印机 PRN、服务器 SRV，
例如 NB-0042。报修、借用、归还都以资产编号为准，员工报修时须提供资产编号。

## 二、保修与维修

1. 在保修期内的故障，一律走厂商保修，IT 报修单里注明「厂商保修」，不得自行拆机。
2. 已过保修期的设备，由 IT 先行维修；预估维修费用超过设备残值一半的，申请换新，不再维修。
3. 同一设备 90 天内因同一问题第二次报修的，直接进入换机评估，不再按单次故障处理。
4. 设备处于「维修中」状态时，可向 IT 申请备用机，归还时间以维修完成通知为准。

## 三、响应时限

| 优先级 | 适用情形 | 响应时限 |
|---|---|---|
| P1 | 影响整个部门或生产业务（服务器、共享打印机故障） | 4 小时内 |
| P2 | 影响个人办公（笔记本、台式机无法使用） | 1 个工作日内 |
| P3 | 其他问题（外设、显示器色差等） | 3 个工作日内 |

## 四、续保与换新

保修到期前 60 天，IT 汇总即将过保的在用设备，提交续保或换新计划，由部门负责人确认。
已报废的设备不再续保，也不再受理报修。

## 五、领用与归还

员工离职或转岗时，须在 5 个工作日内归还所领用的设备，IT 核对资产编号后办理注销或转移。
